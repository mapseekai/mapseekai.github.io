# 章节文字竖向停留与分区交点

日期：2026-10-26。针对用户指出的右侧文字及分区交点细节复查 ArtCraft `/apps` 页面，未改动产品内容、品牌、首页空间动效、导航结构或截图配置。

## 原站实测

浏览器中逐段采样后确认：后续章节文字先从下方队列进入右侧，完整旋转到 -90°，保持竖向沿边移动，再在靠近顶部时逐字转为横向并放大。不是一次短暂的斜向摆动。原站分区两侧标记是 11×11px 容器中的 T 形：横线 11×1px，向下短线 1×6px，位置与横向分隔线和版心竖线的交点对应。

## 本次调整

- 右侧文字分成队列、转入、竖向停留、逐字转横和顶部停靠阶段。竖向阶段为严格 -90°，同一列对齐，字体不会散在斜线上。
- 进度由滚动位置计算，反向滚动沿同一路径返回。旋转中的链接命中区域由实际字形包围盒计算，竖向文字仍可点击、Tab 聚焦及 Enter 跳转。
- 三个产品章节与结尾行动区增加两侧小 T 标记。标记在边界入场时显现，固定导航遮挡前淡出；不常驻高亮，不增加整屏发光框。
- 标记使用纯 CSS，不参与布局、不拦截鼠标、不进入辅助阅读树。首页/详情截图保持原先的一屏完整显示约束。
- 数字阅读标尺、轻微光晕、顶部标题联动、原始 Logo、三处真实截图占位保持不变。没有新增运行依赖。
- 减少动态效果时保留章节导航但不旋转文字；交点标记不做缩放动作。
