# MapseekAI 官网设计

当前版本以 Hallmark Cobalt 为主参考，并保留 Mapseek 绿色品牌。

完整设计规则见 [根目录 design.md](../design.md)。首页使用真实陆地几何构成的字符场、三产品索引、单一交互地图、可切换工作流和文字式文章目录。

新增动效包括可暂停的字符地图、按键反馈、导航下划线、产品切换、区块入场与工作流连线；减少动态效果时全部提供静态状态。新增快速访问支持键盘检索。

保留全部产品、博客、文章、生态及 404 路由。产品内容仍由 `src/content/site.ts` 维护，素材来源见 [asset-sources.md](asset-sources.md)。
