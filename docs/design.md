# MapseekAI 官网设计

2026-10-26 使用 Hallmark 重新设计，按用户要求只继承产品内容，不继承旧版页面布局。

统一设计系统见 [根目录 design.md](../design.md)，实际 Token 见 [src/tokens.css](../src/tokens.css)。

## 页面组成

首页以深绿色首屏承托可切换的地图演示，随后依次展示三个产品、空间工作流、技术生态、文章和产品入口。产品采用纵向大幅展示，不使用旧版三列产品小卡片。

产品页、博客列表、文章页、生态目录和 404 页共享排版、控件、颜色和间距体系。保持原有的 12 条页面路由和独立 404 页。

## 交互

保留图层显隐、示例要素选择、三套地图配色、缩放与重置、键盘标签页、导航菜单、文章搜索、分类筛选及文章目录。所有演示依然使用本地示意数据，不连接实际产品服务。

## 维护

产品事实、文章正文和外部链接仍集中在 `src/content/site.ts`。样式 Token、基础规则与页面布局分别放在 `src/tokens.css`、`src/base.css` 和 `src/styles.css`。

本次验证与截图保存在 `artifacts/hallmark-20261026/`。旧版源码备份在项目相邻的 `mapseekai-website-backups/` 目录，未覆盖原始备份。
