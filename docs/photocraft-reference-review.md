# PhotoCraft 参考分析与细化

参考页面：https://getartcraft.com/apps/photocraft 。检查日期：2026-10-26。
本轮在实际浏览器中检查了首屏、主要截图、功能网格、图库和产品家族区，并读取可见元素的计算样式。参考截图仅保存在忽略目录，不随源码发布。

## 视觉依据

| 观察对象 | 参考页面表现 | Mapseek 的对应调整 |
| --- | --- | --- |
| 顶栏 | 约 50px 高的工具式导航，细分隔线与明确主入口 | 顶栏收至 56px，用正式字标与三个产品名，去掉产品序号 |
| 首屏 | 产品图标、名称、集中大标题、短介绍、行动按钮依次展开 | 使用 Mapseek 原始图标，重排首屏纵向间距，不再绘制装饰图标 |
| 字体层次 | 1440px 视口中，主标题为 Archivo 72px / 620，行高约 73px；功能标题约 60px | 中文标题适当放松行高，拉丁文字使用本地 Avenir Next 回退栈；不搬运参考站的字体文件 |
| 版心 | 1440px 视口中，主要内容约 1280px 宽，大图贴齐版心边界 | 桌面两侧留白约 80px，通栏截图与框架对齐，超宽屏限制内容宽度 |
| 信息节奏 | 先建立产品认知，再显示大幅实际截图，随后解释功能 | 每款产品依次呈现产品名、主张、简述、截图位与具体能力 |
| 功能区域 | 紧凑的标题和文字，通过细线组成开放网格 | 采用无序号的三列能力区；窄屏单列，不堆叠悬浮卡片 |
| 章节导览 | 阅读过程中可识别当前章节 | 侧栏直接显示“总览 / Cloud / Loom / Design”，进度改为无数字细线 |
| 动效 | 状态变化较短，入场与滚动导览配合 | 首屏单次错峰显现、按钮反馈、章节显现；不做文字扰动或强制滚动 |

## 本次明确删除

所有导航、产品章节、功能说明、页尾入口的 00/01/02/03 装饰编号。删除读数标尺的数字、截图占位的大字水印、背景网格、测量角标和可见分辨率提示。截图尺寸要求保留在配置与交付文档，不再占据产品展示区。

首页仍只介绍 Cloud、Loom、Design。原有产品详情、文章及技术生态路由继续保留。这里借鉴参考页的版式节奏与比例，不复制其商标、截图、产品事实、文案或源码。

## 截图与边界

真实截图仍由用户提供。无图时明确显示“预留给真实产品截图”，仅预留展示面积，不生成产品 UI 冒充截图。已配置的图片沿用实际宽高比，完整显示且支持放大。官网内的合成交互示例只在详情页折叠区提供，并保留说明。
