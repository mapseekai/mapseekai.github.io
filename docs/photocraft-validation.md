# PhotoCraft 参考版验证

日期：2026-10-26。用户指定参考 PhotoCraft 官方产品页，并要求真实产品截图先预留位置。

## 本版变化

首页和三个产品详情页改为浅灰/深色双主题、粗字标题、细线分栏、编号和大幅截图。旧山景首屏与首页模拟工作台移除。三个截图位置由 `src/content/product-media.ts` 共用，当前均为明确占位；详情页继续保留折叠的本地交互示例。

没有复制参考网站的品牌素材、截图、文案或源码；本版组件独立实现。

## 修复和边界

初次检查发现窄屏截图容器的最小高度会通过 aspect-ratio 推高宽度，已显式约束宽度后复测全部通过。阅读百分比补充 progressbar 语义。首次详情页测试返回 DOM 对象导致工具序列化报错，改为返回布尔值后三个页面重新验证通过。

自动无障碍结果中，导航伪元素和装饰水印仍有对比度 `incomplete` 项；不能据此宣称完整 WCAG 合规。截图尚未提供，因此无法验证实际产品截图中的文字可读性。

浏览器操作使用 Ego。Playwright 回归脚本已按新的截图/折叠示例需求维护，本轮未执行 Playwright 套件。参考图、测试图、截图和原始检查数据保存在本地忽略目录 `artifacts/photocraft-20261026/`，不提交到公开仓库。
