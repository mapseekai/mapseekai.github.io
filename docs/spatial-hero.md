# 动态空间画布首屏

参考：ArtCraft 官网首页 https://getartcraft.com/ 。本次检查了首页实际运行的环形场景、图片环绕、鼠标响应和滚动过渡。没有复用参考站的图片、视频、Logo、字体文件或页面源码。

## 设计

将参考站的“创作作品环绕中心”转化为适合 Mapseek 的地图图层演绎。同一片合成空间分别呈现地形等高线、图层、几何节点、要素面和地图样式，围绕标题形成空间层次。图形由本地 SVG 绘制，不使用外部图片服务，也不把这些图形当作真实产品界面。

首屏文案仍然是“为地理空间工作，重新设计工具”。保留 Mapseek 项目原始图标和字标。中心排版压缩为品牌、主张、介绍和两个入口，给空间图形留出展示位置。

## 交互

- 首屏可见时，五块地图切片缓慢漂浮，精细指针带来轻微视差。
- 下滚时，切片按同一条进度曲线叠合成地图图层，中心文案让开；随后接入 Cloud、Loom、Design 三个入口。向上滚动可反向展开，没有强制整屏跳转。
- 悬停或键盘聚焦产品入口，对应类型的图层边缘强调。点击仍然前往相应产品章节。
- 提供暂停/播放按钮；暂停保留当前动画位置，不重置到起点。
- 离开首屏可视范围停止连续帧循环；隐藏页面停止推进；系统减少动态效果时只显示静态构图，不增加滚动过渡的额外高度。
- 无 JavaScript 时，标题、原 Logo、五个图层和产品入口仍由 SSR 输出，隐藏无作用的播放按钮。

图形标注“空间图层演绎 · 非产品截图”。三处真实产品截图继续保持空配置，不被本次图形替换。

## 实现

- `src/components/SpatialHero.tsx`：确定性 SVG 场景、动画生命周期、暂停与指针响应。
- `src/spatial-hero.css`：首屏、明暗配色、滚动停留区和移动端构图。
- `tests/spatial-hero.test.mjs`：静态输出、品牌插画边界、动作与清理契约。

没有增加运行依赖。动态变化主要更新有限数量元素的 transform/opacity，SVG 的路径内容保持静态。
