## 记录与边界

初次 SVG 节点聚焦调用被 Ego 的选择器层拒绝，随后用真实 Tab 键进入节点，方向键编辑和撤销均通过。首次轨迹复查脚本误将浏览器的 innerWidth 写在 Node 侧，修正测试脚本后复查通过；未更改产品行为绕过测试。所有记录保留。

部分装饰文字/透明层的自动对比度检查仍返回 incomplete，不将自动扫描结果表述为完整无障碍认证。

本轮浏览器执行使用 Ego；更新了 Playwright 回归脚本，但没有运行 Playwright 套件。参考站的动画机制与比例已实测，未声称跨浏览器的像素级完全一致。
