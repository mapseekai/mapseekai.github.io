# PhotoCraft 滚动交互复现

参考：<https://getartcraft.com/apps/photocraft>。本次在浏览器中检查了页面首屏、章节过渡、截图和功能区，并采样了滚动时的实际样式。

## 已观察到的机制

参考站使用 Lenis 1.3.23，惯性插值参数 `lerp: 0.12`；顶部主导航约 49px。右侧当前章节不是静态的小号目录：后续章节文字从右下方逐字沿弧线向上移动，当前章节放大，已读章节缩小并在顶部排列。内容进入视口时伴随短距离位移、清晰度与透明度变化。

本次根据这些可观察行为独立实现，未搬运参考网站的专有页面代码、字体文件或品牌资产。

## Mapseek 实现

- 顶栏固定为 48px，下方增加 36px 的固定上下文标题条；手机下方标题条为 34px。
- 标题条随阅读位置显示当前产品及“产品界面 / 产品能力”，使用上下滑入过渡。
- 右侧章节文字与顶部标题共用一个进度源。逐字曲线过渡由滚动位置决定，可正向或反向；移动端不显示遮挡正文的浮动文字。
- 使用参考站同版本 Lenis 及 `0.12` 插值。保持触屏原生滚动；锚点点击更新地址栏、处理固定导航偏移，键盘访问保持焦点。
- 采用一次性、短距离入场，按产品标题、说明、按钮错峰呈现；分隔线和截图随进入视口呈现。
- 版心最大 1280px；1440px 桌面约 120px 侧留白，比上一版更充裕。窄屏保留安全边距。

## 一屏截图

截图框高度同时受容器宽度、可视窗口高度及 660px 上限控制。高度计算预留顶栏、上下文条、图片标题、说明及底部空间，不仅约束图片本身。

图片始终 `object-fit: contain`，不裁切界面边缘；长竖图缩小至可视范围。原图查看器也限制于当前屏幕，不再产生必须纵向滚动才能看到整图的弹窗。

截图仍未提供，保留原来三处明确的真实截图占位。测试图片只用于本地尺寸验证，不发布，也不冒充产品界面。

## 保持与边界

Mapseek 原始 Logo、字标、favicon 原样保留；首页仍只有三个产品。装饰性的 01、02、03 和可见百分比读数不再显示。原有产品详情页、折叠示例及文章路由继续保留。

减少动态效果时销毁惯性滚动实例，恢复原生滚动并停止入场和字母轨迹。页面在后台时暂停帧循环；组件卸载移除监听器和尺寸观察器。无 JavaScript 时正文与截图占位可读。
