# 导航、页脚与数字阅读标尺

日期：2026-10-26。参考用户给出的 ArtCraft / PhotoCraft 页面和两张局部截图，保留 Mapseek 原始 Logo、三款产品与真实截图占位。

## 实现

- 全站顶部统一为“产品、资源、价格、博客”。产品下拉列出 Cloud、Loom、Design；资源下拉按资源、产品笔记、社区分栏。菜单支持点击、方向键、Home/End、Esc、焦点返回及点击外侧关闭。手机使用可滚动的折叠菜单。
- 页脚由品牌说明、产品、Mapseek、资源、社区组成，桌面采用 2:1:1:1:1 比例、贯穿式细分隔线、无悬浮卡片。资源链接在顶部和页脚复用同一配置。
- 右侧恢复 0–100 的阅读刻度，5% 为主刻度；当前位置使用逐位滚动的百分比。刻度随页面滚动，读数与真实 scrollY 一致。
- 参考站实际指示线采用 6px 品牌色光晕；本站以 Mapseek 绿实现相同强度，章节文字保留纸面色柔光，不增加持续闪烁。
- 标尺可以点击、拖动，或聚焦后使用方向键、PageUp/PageDown、Home/End；支持减少动态效果。章节标题同步、文字弧线与 Lenis 原有配置保留。
- 原有正文和产品区仍不显示 01/02/03 装饰编号。阅读数字不是产品序号。

新增 `/resources/` 汇集已有产品笔记及开放项目；`/pricing/` 明确显示“价格信息待补充”。没有虚构套餐金额、购买入口、邮箱、Discord 或其他社交账号。共 14 个静态页面及独立 404。

布局覆盖 320×568、375×667、414×896、760×900、768×1024、1024×600、1280×720、1440×900、1920×1080、812×375。页面覆盖首页、三款产品、资源、价格、博客、开放生态。

首次检查发现 320px 桌面模拟视口中，全局 body 最小宽度挤占滚动条空间，以及深色生态页面仍引用旧的深绿色文字 Token。分别修复最小宽度与主题变量映射后完整复测通过。一次新增静态断言未匹配普通刻度类名的尾部空格，清理类名后通过，保留原始记录。

部分动态标题、透明图层和旧文章图形的对比度仍有工具无法判定的 incomplete 项，不能据此宣称完整 WCAG 合规。浏览器操作经 Ego 执行；维护了 Playwright 回归脚本，本轮未运行 Playwright 套件。
