# 产品官网版本验证

日期：2026-10-26。该版本按照用户要求取消主题框架限制，首页仅表达 Cloud、Loom、Design 三款产品。

## 实际执行

| 项目 | 结果 |
| --- | --- |
| TypeScript、Vite 客户端及 SSR 构建 | 通过 |
| 静态测试 | 11/11 通过 |
| 浏览器功能检查 | 12/12 通过 |
| 响应式布局 | 40/40 通过 |
| Axe WCAG A/AA 扫描 | 5 个页面/视口组合，无确定违规 |
| 正常动效 | 观察到样式切换的 `artboard-enter` 动画 |
| 减少动态效果 | 显式设置媒体偏好后，功能可用且没有运行中的动画 |
| 无 JavaScript | 首页正文、3 个产品章节、卫星影像及 2 个 SVG 示例仍显示 |

布局覆盖 320、375、414、768、1024、1280、1440、1920px；每种宽度检查首页、三个产品详情页及博客列表。浏览器功能覆盖资源选择、图层显隐、节点键盘编辑/拖拽/撤销/重置、三套配色、标注开关、SVG 下载、手机菜单与运行错误收集。

第一次减少动态效果检查没有在新的浏览器命令会话中显式设置媒体偏好，因此不能用于判断实现。随后显式设置并复测通过，保留初次记录。

首次无障碍扫描发现 4 处辅助文字对比度问题和配色分组缺少角色，已加深颜色并补充原生语义后复测。影像、SVG、渐变覆盖和粘性导航附近的一部分对比度仍属于工具的 `incomplete` 项，不能据此宣称完整 WCAG 合规。

## 检查边界

浏览器操作通过 Ego 执行。维护了匹配当前页面行为的 Playwright 回归脚本，本轮没有执行 Playwright 套件。旧版首页的字符地图和工作流测试被新的产品交互需求替换，原有静态路由/链接测试保留。

三个预览都是官网功能示意；不把示例几何坐标、资源数量或影像标注当成真实产品指标。不使用上一轮概念图中的虚构客户数据、测试数字或登录入口。
